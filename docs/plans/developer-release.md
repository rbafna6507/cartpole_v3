# Developer release plan — 2026-10-27

Goal: a visitor can install, simulate a supplied actor, change a controller,
replay observations and prepare a portal submission in about 30 minutes.

1. Preserve the current SDK and hash-bound numerical actor runtime in a clean repo;
   copy only required model/profile inputs, no operational credentials or raw archives.
2. Curate measured system identification, reproduction plots and a hardware inventory.
   Keep rejected models, configured values and assumptions explicitly separate.
3. Verify the completed controlled-swing campaign and preserve a clearly labelled
   research checkpoint without replacing the working operator policy.
4. Provide simulation/replay/submission, data analysis and short training/export examples.
   Document source frames, units, timing, safety authority and transfer limitations.
5. Test from this repository's environment, review the public file inventory and
   credential scan, then initialize and publish the new repository.

Acceptance: fresh simulation install; supplied actor and Python example execute;
replay succeeds; training/export smoke succeeds or the exact limitation is documented;
curated CSV plots regenerate; actor provenance checks pass; no motion is needed.
Native firmware AUTO is established on this rig. External Python AUTO remains a
research trial; publication must not imply repeatable hardware qualification.
